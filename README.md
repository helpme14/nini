# Ni Microsite

## Install

```bash
npm install
npm run dev
```

## Stack

- React
- Vite
- TypeScript
- TailwindCSS
- Framer Motion

## Features

- Mood-based reactions
- Interactive timeline
- Floating ambient particles
- Smooth cinematic transitions
- Comfort card mini game
- Final branching interaction
- Subtle confetti
- Music toggle
- Cursor glow
- Responsive UI
